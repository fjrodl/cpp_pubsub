# Contributing

Gracias por tu interés en contribuir a este proyecto.

## Cómo contribuir

1. Haz un fork del repositorio.
2. Crea una rama para tu cambio (`git checkout -b mi-mejora`).
3. Realiza tus cambios y asegúrate de que las pruebas de linting y compilación pasen.
4. Commit con un mensaje descriptivo.
5. Push a tu rama y abre un Pull Request.

## Estilo de código

Este proyecto sigue las convenciones de estilo de ROS 2 para C++ (2 espacios de indentación) y se valida con `ament_lint_auto` (copyright, cpplint, lint_cmake, uncrustify).
